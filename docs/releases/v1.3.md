## SevenMac 1.3, edit without unpacking

Open a file inside an archive, make a change, save it back. This release adds an in-app text editor and file replacement, including Android APK containers.

### Highlights

- View and edit UTF-8 text inside ZIP, 7z and TAR archives. JSON, XML, config files and scripts stay at their original paths. Use **View / Edit** or double-click a file; press **Cmd+S** to save.
- Replace binary files inside an archive without unpacking it by hand.
- Saves run on a temporary copy, pass a 7-Zip integrity test, then replace the original. A separate backup is kept beside the archive. If another app changes the archive while you edit, saving stops instead of overwriting it.
- Search across all folders in an archive. Recent archives, clearer empty states and an editable/read-only status make navigation less fiddly.
- More recognized containers: APKS/XAPK/AAB, Office and OpenDocument files, EPUB, comic archives, Python wheels, VSIX, MSIX and virtual disk images. **Open as Archive** also tries files with an unfamiliar extension.
- Open supported files from Finder. Read-only formats remain available for browsing, viewing and extraction.
- Updated app icon with a more balanced 7z mark and a simpler zipper.

### Fixes

- Fast navigation no longer shows results from a folder you already left.
- Literal wildcard characters in file names no longer select unrelated entries.
- ZIP password encryption now explicitly uses AES-256.
- Folder sizes, empty files, cancelled jobs and inaccessible folders are handled more accurately.
- GZIP/BZIP2/XZ creation now explains the single-file restriction. Zero-size split volumes are rejected.
- Release builds include the engine license and run automated archive checks before packaging.

### Install

1. Download `SevenMac.dmg` below.
2. Open it and drag **SevenMac** into **Applications**.
3. First launch only: right-click the app and choose **Open**. This build is ad-hoc signed, not notarized by Apple.

### Notes

- Requires macOS 13 Ventura or newer, Apple Silicon.
- Uses the unmodified official 7-Zip 26.02 engine. Swift code is MIT; bundled engine licensing is included in the app.
- The text editor supports UTF-8 files up to 2 MB. Other files can be replaced; RAR and disk images are read-only. Recognition does not mean every variant or codec is supported.
- Editing APKs or other signed packages invalidates their signature. Android binary XML, DEX decompilation, zipalign and signing are not included. Use the Android build tools before installing a modified APK.
- Container editing does not validate an Office document, EPUB or app package’s internal schema.
